# Changelog

## [0.1.0] — Andamiaje inicial
- Estructura completa del proyecto (backend, frontend, assets, cpp, database, docs, tests, scripts).
- Backend Flask con blueprints (`home`, `api`, `contact`) y plantillas Jinja2 componetizadas.
- Sistema de diseño (paleta ámbar/índigo sobre tinta oscura, tipografía Space Grotesk + Inter + JetBrains Mono, tema claro alternativo).
- JS modular (ES modules): navbar, scroll reveal, cursor personalizado, partículas ambiente, galería con lightbox, reproductor de música, formulario de contacto.
- Base de datos SQLite con tabla `contact_messages` ya inicializada.
- Mirror estático en `frontend/` (HTML/CSS/JS sin dependencias de Flask).
