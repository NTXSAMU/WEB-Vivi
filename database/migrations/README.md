# migrations/

De momento la web no usa base de datos: todo el contenido editable vive en
`backend/data/content.json` (notas, planes, cosas que le gustan, recuerdos,
preguntas...) y se versiona con git como cualquier otro archivo.

Esta carpeta se deja preparada por si en el futuro se añade algo que sí lo
necesite (por ejemplo, si Viktoria pudiera dejar sus propias notas desde la
web y quisierais guardarlas en algún sitio).
